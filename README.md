## ✨ Features
- Password-only authentication (Student)
- Password + Mobile OTP (Teacher)
- Password + Mobile OTP + Email OTP (Admin)
- Role-based access control
- Failed-login lockout
- Real-time audit logging
- Admin dashboard with full user management

## 🔐 Security Highlights

- Server-side sessions with HttpOnly cookies
- CSRF protection
- Rate limiting
- Admin IP whitelisting
- OTP hashing and single-use enforcement
